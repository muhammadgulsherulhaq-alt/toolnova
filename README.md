# ToolNova

A zero-cost static website starter with four browser-based creator tools:
- Caption Generator
- Hashtag Ideas
- Content Ideas
- Video Title Generator

## Run locally
Open `index.html` in a browser. No build tools, API key, backend, or account are required.

## Publish for free with GitHub Pages
1. Create a GitHub repository named `toolnova`.
2. Upload all files in this folder (not the ZIP file itself).
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main`, folder `/(root)`, then Save.
6. Wait for the Pages deployment and open the URL shown in Settings → Pages.

## Before public launch
- Replace `hello@toolnova.example` with an email address you control.
- Test every tool on mobile and desktop.
- Add original, useful articles and clear author/editorial information.
- Add a real privacy policy that reflects any analytics, advertising or third-party services you later enable.
- Do not apply for advertising until the site has substantial useful content and complies with the ad network's policies.

## Important
These first tools use local templates, not an AI model. They work without an API key, but their output is a starting point rather than AI-generated research. Do not claim they are powered by AI. A future AI integration would need a secure backend and an appropriately protected API key.
